# 🎉 Happy Birthday Vesta 🎉

A romantic birthday website created with love for Vesta from Dilip.

## Features

- **Beautiful Birthday Theme**: Purple and gold color scheme with elegant animations
- **Interactive Slideshow**: Romantic birthday messages with smooth transitions
- **Animated Elements**:
  - Floating balloons
  - Falling confetti
  - Sparkling effects
  - Birthday cake with flickering candles
- **Background Music**: Optional romantic background music
- **Responsive Design**: Works perfectly on all devices
- **Easter Eggs**: Special effects triggered by interactions

## How to Use

1. Open `index.html` in your web browser
2. Click "Begin Your Special Day" to start the experience
3. Navigate through the birthday messages using:
   - Arrow buttons
   - Dot navigation
   - Keyboard arrows (left/right)
   - Spacebar (next message)
   - Enter (go to final message)
4. Enjoy the animations and music!

## Adding Background Music

To add background music:
1. Add an MP3 file named `birthday-music.mp3` to the project folder
2. The music will be available through the music toggle button

## Customization

### Colors
The main color scheme uses:
- Primary: Purple (`#667eea` to `#764ba2`) gradient background
- Accent: Gold (`#FFD700`)
- Romantic: Pink (`#FF69B4`)

### Messages
Birthday messages can be customized in the HTML file within the `.message` divs.

### Animations
All animations are CSS-based and can be adjusted in the `style.css` file.

## Browser Compatibility

- Modern browsers (Chrome, Firefox, Safari, Edge)
- Mobile responsive
- Requires JavaScript enabled
